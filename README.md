# [Tag Stacker](https://slimeknights.github.io/projects/#tag-stacker)

This is a Minecraft mod allowing items to stack together in the inventory if they share one of a set of tags.

By default, this supports any common tag prefixed with `ingots/`, `nuggets/` or `storage_blocks/`, along with several mod specific tags. Additional tags can be added using the config, along with blacklisting specific tags with those prefixes.
